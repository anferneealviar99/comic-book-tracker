# Comic Tracker

## 📖 About
Comic Tracker allows users to add comic books to their reading list and see comics that release in the current week.

## 🏆 Attribution & Credits
This project relies on external data and open-source tools. Proper attribution is a core priority of this project.

* **Comic Data:** All comic book data, including issue details, characters, creators, and cover art, is provided by the **[Metron API](https://metron.cloud/)**. 
* **Framework:** Built with **[Django](https://www.djangoproject.com/)**.
